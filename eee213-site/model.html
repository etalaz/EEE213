Data and model: linear regression

Method 1 applied to the combined cycle power plant data. Code: linear_regression.py.

Data

Hourly averages from a combined cycle power plant (gas and steam turbines), 2006–2011, full load only. File: ccpp.csv.

ColumnQuantityUnit
ATAmbient air temperature°C
VSteam-turbine exhaust vacuumcm Hg
APAmbient air pressurembar
RHRelative humidity%
PENet electrical energy output (target)MW

Source: P. Tüfekci and H. Kaya, "Combined Cycle Power Plant," UCI Machine Learning Repository, 2014, doi:10.24432/C5002N. Licence: CC BY 4.0.

Checks

  • Rows: 9,568 (count). Missing values: 0 (count).
  • Exact duplicate rows: 41 (count). Decision: keep them, because the rows are hourly averages rounded to two decimals and none is proven to be an error.
  • All values lie in plausible ranges for the plant (for example AT 1.81–37.11 °C, PE 420.26–495.76 MW).

Split

Split once, before any training: the first 7,654 rows are the training set and the last 1,914 rows are the test set (counts). The model is fitted on the training set only and evaluated once on the test set.

Model

Linear regression: the predicted output is a weighted sum of the features plus an intercept, PE = w1·AT + w2·V + w3·AP + w4·RH + b. Training chooses the weights that minimise the sum of squared errors (least squares). Linear regression has no hyperparameter.

Baseline and error

The baseline always predicts the training mean of PE, 454.44 MW. Error measure: mean absolute error (MAE) in MW on the 1,914 test rows.

ModelTraining MAE (MW)Test MAE (MW)
Baseline (training mean)–14.72
Linear, AT only4.274.33
Linear, four features3.623.66

Fitted four-feature model (weights in MW per unit of the feature): AT −1.992, V −0.227, AP +0.062, RH −0.161, intercept 454.98 MW. The test error of 3.66 MW is about a quarter of the baseline error. Training and test errors are close (3.62 and 3.66 MW), so there is no sign of overfitting.

Limits

The data were recorded at full load, so the model cannot be trusted at other loads. A straight line cannot capture curved relationships, so a more flexible method such as k-nearest neighbours can do better on the same split.
