How to run

Python with NumPy, pandas, SciPy and scikit-learn is needed. Run each command from the repository folder. ccpp.csv must be in the same folder.

pip install numpy pandas scipy scikit-learn
python w09.py
python linear_regression.py
python newton_diode.py
